# pynk_p Smoothing Groups — 1.0.1

Created by pynk_p

Blender **5.2.3 LTS**용 애드온. UI는 영어이며 3D Viewport 사이드바의
`pynk_p` 탭에 두 패널이 나타납니다.

- `Smoothing Groups`
- `Subdivision By Smoothing Groups`

### 📦 [최신 버전 다운로드 (`pynkp_smoothing_groups-1.0.1.zip`)](https://github.com/PynkP/pynk_p_smoothing_groups/releases/latest)

## 설치

1. ZIP 파일을 다운로드합니다. 압축은 풀지 않습니다.
2. Blender에서 `Edit > Preferences > Add-ons`를 엽니다.
3. 우측 상단 메뉴의 `Install from Disk...`에서 ZIP을 선택하고 설치합니다.
4. 애드온이 활성화되어 있는지 확인합니다.
5. 메시를 선택하고 3D Viewport에서 `N`을 눌러 `pynk_p` 탭을 엽니다.

패널 제목이 잘리면 사이드바의 왼쪽 경계를 드래그해서 폭을 넓히세요.
이 애드온은 선택한 메시가 있을 때 패널을 표시합니다.

## 수동 그룹 지정

1. 메시 선택 → `Tab` → Edit Mode.
2. Face Select 모드에서 면을 선택합니다.
3. `Smoothing Groups`의 번호를 클릭합니다.

| 클릭 | 면의 그룹 |
|---|---|
| 1 | 1 |
| 2 | 1, 2 |
| 2 다시 클릭 | 1 |
| 1 다시 클릭 | 없음 |

- 버튼 표시는 **선택한 면 전체의 그룹 합집합**입니다.
- 선택한 면 중 하나라도 번호를 가지고 있으면 그 버튼이 켜집니다.
- 켜진 번호 클릭: **선택 면 전체에서 그 번호 제거**.
- 꺼진 번호 클릭: **선택 면 전체에 그 번호 추가**.
- 선택이 바뀌면 버튼 표시도 따라 바뀝니다.
- 번호 지정·제거·Clear Groups·Auto Smooth는 노말과 연결된 경계를 즉시 갱신합니다.
- `Assign Mode`, 별도의 `Update Normals` 버튼은 없습니다.
- `Clear Groups`는 선택한 면의 모든 그룹을 해제합니다. 그룹이 없는 면은 Flat 처리됩니다.
- `Group` 번호를 정하고 `Select`를 누르면 해당 그룹의 보이는 면을 선택합니다.
  기존 보이는 면 선택은 교체하며 숨긴 면을 드러내지 않습니다.

## 각도로 자동 분류

1. 자동 분류할 면을 선택합니다.
2. `Angle`을 설정합니다. 기본값은 30°입니다.
3. `Auto Smooth`를 누릅니다.

인접 면의 노말 사이 각도가 임계값 이하이면 공통 그룹을 갖도록 배정하고,
초과하면 공통 그룹이 없도록 배정합니다. 꼭짓점에서 만나는 큰 각도의 면도
잘못 섞이지 않도록 제약을 추가합니다. 중간 면에는 여러 그룹이 배정될 수 있습니다.

선택한 면의 기존 그룹은 교체되며, 선택하지 않은 면의 그룹 값은 그대로입니다.
자동 배정은 선택 경계를 부드럽게 연결하지 않도록 주변 미선택 면의 번호를 피합니다.
전체 모델을 각도 기준으로 분류하려면 전체 면을 선택하세요.

서로 충돌하지 않는 영역은 번호를 재사용합니다. 예를 들어 상자의 마주 보는 면이
같은 번호를 사용하는 것은 정상입니다. 30개 번호 안에 배정하지 못하면 오류를
표시하고 기존 그룹을 변경하지 않습니다. 이 배정기는 결정적인 휴리스틱이며,
가능한 모든 조합을 탐색하는 최적화 솔버는 아닙니다.

## 그룹 기반 Subdivision

1. 그룹을 먼저 지정합니다.
2. `Subdivision By Smoothing Groups`에서 `Add Subdivision`을 누릅니다.
3. `Viewport Levels`와 `Render Levels`를 조절합니다. 기본값은 각각 2입니다.
4. `Use Smoothing Groups`를 켜거나 끄며 결과를 확인합니다.

공통 그룹이 없는 경계에 평가 시점의 Edge Crease 1을 적용합니다.
공통 그룹이 있는 경계에는 그룹에 의한 추가 Crease를 적용하지 않습니다.
기존 사용자의 Crease는 `max(기존 값, 그룹 경계 값)`으로 보존됩니다.
따라서 기존 Crease가 있으면 같은 그룹 안에서도 날카로운 형태가 남을 수 있습니다.

연동을 끄면 그룹에 의한 추가 Crease만 사라집니다. 원본 Crease는 그대로이며,
노말의 그룹 제어는 계속 작동합니다. 그룹이 없는 면은 모든 이웃과 경계로 간주하므로,
그룹 없이 Subdivision을 추가하면 형태가 예상보다 날카롭게 유지될 수 있습니다.

`Show in Viewport`, `Show in Render`는 각각 작업 화면과 렌더 표시를 제어합니다.
`Remove SG Subdivision`은 이 툴이 관리하는 Subdivision 및 경계 모디파이어를 제거합니다.
그룹 정보와 그룹 노말 모디파이어는 유지합니다.

### 맥스와의 차이

이 버전의 Subdivision은 **Crease 기반 구현**입니다.
3ds Max TurboSmooth의 `Separate by Smoothing Groups`와 모든 꼭짓점·경계에서
동일한 토폴로지 또는 위치를 만든다는 보장은 없습니다. 맥스 실행 환경에서의
대조 검증은 아직 하지 않았습니다.

노말은 동일한 매니폴드 꼭짓점 팬 안에서 **공통 그룹이 있는 면의 코너 각도로
가중 평균**합니다. `A={1}, B={1,2}, C={2}`일 때 A와 C를 B 때문에 같은 그룹으로
합치지 않습니다. 맥스의 모든 노말 가중 방식과 비트 단위로 같음을 보장하지 않습니다.

## 모델링 이후 갱신

그룹 버튼 조작은 자동 갱신됩니다. 다만 **버텍스 이동, Extrude, Bevel, Merge 등
메시 형상 편집 후에는 `Update Boundaries`를 한 번 눌러 주세요.**
이 버튼은 경계뿐 아니라 그룹 노말도 함께 다시 계산합니다.
Subdivision을 추가하지 않은 상태에서도 이 버튼을 사용할 수 있습니다.

일반 메시 편집으로 생긴 새 면은 Blender가 CustomData를 보간·복사한 값을 가질 수
있습니다. 의미 있는 그룹 상속을 모든 편집 도구에 대해 보장하지 않으므로,
새 면의 번호를 확인하고 필요하면 다시 지정하거나 Auto Smooth를 실행하세요.
이 버전은 모든 모델링 이벤트를 감시하는 상시 갱신 핸들러를 설치하지 않습니다.

## 원본 데이터와 모디파이어 순서

모디파이어 스택 앞부분은 다음 순서를 유지합니다.

1. `pynk_p • Smoothing Groups`
2. `pynk_p • SG Boundaries` (Subdivision을 추가한 경우)
3. `pynk_p • Subdivision By Smoothing Groups`
4. 다른 모디파이어

노말 자료가 기본 메시에서 계산되므로 앞에 다른 토폴로지 변경 모디파이어를 두지
않습니다. 순서를 변경하면 관련 작업이 오류와 함께 중단됩니다.
추가 시 기존 모디파이어들은 위 세 개 뒤로 이동하므로 결과를 확인하세요.
기존 사용자의 Subdivision을 자동 연결하거나 삭제하지는 않습니다.

관리 중인 Subdivision은 이름으로 연결되므로 이름을 변경하지 마세요.
실수로 이름을 바꿨다면 원래 이름으로 복구하는 것이 가장 간단합니다.
연결이 끊긴 상태에서 `Remove SG Subdivision`은 확인 가능한 경계 모디파이어만
지우며 이름이 바뀐 Subdivision을 추측해서 삭제하지 않습니다.

원본의 `sharp_edge`, `crease_edge`, 기존 커스텀 노말은 직접 덮어쓰지 않습니다.
효과는 평가된 메시의 Geometry Nodes 모디파이어에서 적용됩니다.
기존 커스텀 노말과 혼합하는 기능은 없으며, 효과가 켜져 있는 동안 그룹 노말이 우선합니다.
원래 셰이딩을 보려면 그룹 노말 모디파이어의 표시를 끄세요.

그룹 정보와 노드 그룹은 `.blend`에 저장됩니다. 애드온을 꺼도 저장된 모디파이어는
동작하도록 남겨둡니다. 저장된 모델의 효과를 없애려면 모디파이어를 제거해야 합니다.

## 지원 범위

- 로컬 단일 메시, Object/Edit Mode.
- Multi-object Edit Mode와 여러 오브젝트가 공유하는 Mesh 데이터는 지원하지 않습니다.
  공유 메시라면 먼저 Single User로 만드세요.
- 링크·라이브러리 오버라이드 데이터에는 쓰지 않습니다.
- 비매니폴드 엣지는 경계로 취급합니다.
- 리깅·애니메이션·모든 모디파이어 조합에 대한 검증은 포함하지 않았습니다.
- 언리얼/FBX 왕복 검증은 포함하지 않았습니다. 그룹 번호의 교환과 최종 노말 내보내기는
  별개이며, 내보내기 시 모디파이어 적용 및 노말 설정을 확인해야 합니다.
- 그룹 번호의 동적 색상은 Blender 테마의 눌린 버튼 표시를 따릅니다.

## 검증

Blender 5.2.3 LTS에서 백그라운드 실행으로 검증했습니다.

- 그룹 규칙 단위 테스트 11개 (무작위 관계 200개 사례 포함).
- 실제 Blender 통합 검사 38개: 등록, Edit Mode 토글, 합집합 표시 데이터,
  각도 분류, 원본 보존, Subdivision 형태 변화, 갱신, 저장·재열기, 다중 그룹 코너 노말.
- Edit Mode 그룹 변경 및 Subdivision 추가의 Undo/Redo 검사.
- Blender 확장 패키지 manifest 검증.

패널을 실제 데스크톱에서 클릭하는 수동 UI 검증과 맥스 결과 대조는 별도로 필요합니다.
소스와 개발 테스트는 ZIP 안에 포함되어 있습니다. 구조는 `ARCHITECTURE.md`를 참고하세요.
